# Tennis Tournament Telegram Bot

Этот проект — Telegram-бот для управления теннисным турниром с локальным хранением данных в SQLite.

## Что улучшено
- рефакторинг логики в отдельные модули: config, db, services, handlers;
- добавлена базовая валидация входных данных и счётов матчей;
- добавлена команда /stats для просмотра статистики игроков;
- добавлены unit-тесты для ключевой логики.

## Быстрый старт
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Скопируйте файл `.env.example` в `.env` и укажите ваш `BOT_TOKEN`.
3. Запустите бота:
   ```bash
   python bot.py
   ```

## Команды
- `/start` — приветствие и подсказка
- `/register_player Имя` — добавить игрока
- `/players` — список игроков
- `/result Победитель Проигравший 6:3 7:5` — внести результат матча
- `/table` — показать турнирную таблицу
- `/stats` — показать статистику игроков
- `/cancel` — отменить текущее действие

## Inline-кнопки
В боте есть меню с кнопками:
- Регистрация
- Игроки
- Таблица
- Статистика
- Результат матча

Если вы начали добавление игрока или результат матча, нажмите кнопку "Отмена", чтобы выйти из режима ввода.

## Тесты
Запуск:
```bash
python -m unittest discover -s tests
```

## Развёртывание на Render
1. Загрузите проект в GitHub.
2. Создайте новое Web Service на Render.
3. Укажите начальную команду: `python bot.py`.
4. В разделе Environment добавьте переменные:
   - `BOT_TOKEN` — токен Telegram-бота;
   - `DATABASE_URL` — URL PostgreSQL базы;
   - `ALLOWED_JUDGES` — список ID судей через запятую (опционально).
5. Убедитесь, что `requirements.txt` содержит `psycopg2-binary`.

### Использование внешней базы
- `DATABASE_URL` должен быть в формате:
  `postgres://user:password@host:port/dbname`
- Если вы не хотите PostgreSQL, оставьте `DATABASE_URL` пустым и используйте локальный SQLite через `DB_PATH`.
